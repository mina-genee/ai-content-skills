# AI Content Agent Skills

A curated collection of AI agent skills for content creators, community builders, and founders. Built for Claude Code and Antigravity.

## Skills

| Skill | Description |
|-------|-------------|
| brand-context | Provides the foundational brand context for other skills. |
| post-writer | Writes engaging social media posts. |
| carousel-writer | Writes structured content for social media carousels. |
| content-repurposer | Repurposes existing content into new formats. |
| hook-writer | Generates catchy hooks for social media content. |
| content-strategy | Develops long-term content strategies. |
| content-calendar | Plans out a content calendar for social media. |
| community-marketing | Skills for marketing within and for communities. |
| co-marketing | Strategies and content for co-marketing campaigns. |
| email-marketing | Writes engaging email campaigns. |
| copywriting | General copywriting skills for varied content. |
| customer-research | Assists in researching target audiences and customers. |
